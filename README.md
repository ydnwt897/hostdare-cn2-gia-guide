## **常见问题：买HostDare前最好先看这几条**

**Q：HostDare支持退款吗？**
支持，但有条件。CN2 GIA系列享有3天退款保证，申请退款需要通过后台工单提交，处理时间24-72小时。退款会扣除0.5-1美元的手续费。需要注意的是，如果当月流量已使用超过20%，退款申请可能被拒。

**Q：VPS部署好之后怎么登录？**
付款完成后你会收到系统邮件，里面有服务器IP、SSH端口（默认22）和root密码。Mac用户直接用终端，Windows用户可以用PuTTY或者Windows Terminal，输入 `ssh root@你的IP` 回车输密码就进去了。

**Q：IP被墙了怎么办？**
新IP被封的用户可以免费申请更换一次，之后再封则需要付费更换。建议购买后先测试IP的连通性。

**Q：可以装Windows系统吗？**
可以，但需要自带Windows授权，HostDare不提供系统许可证。CKVM系列建议CKVM3及以上，CSSD系列建议CSSD3及以上，内存太小跑Windows会很痛。

**Q：有IPv6吗？**
HostDare支持IPv6，但默认不分配，需要购买后**提交工单**向客服免费申请，一般比较快就能开通。
